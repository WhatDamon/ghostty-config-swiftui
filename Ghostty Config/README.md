# Native Xcode workspace

The release-facing project documentation, build commands and attribution are in
[the repository README](../README.md). Open `Ghostty Config.xcodeproj` here.

For commands from this directory, use `-project 'Ghostty Config.xcodeproj'`.
Regenerate reviewed data and bundled notices with `python3 scripts/sync-web-settings.py`.

This is the unofficial SwiftUI port by Damon Lu (@WhatDamon), based on the Apache
2.0 Web project by Zerebos. See root `LICENSE`, `NOTICE`, `THIRD_PARTY_NOTICES.md`,
and `LICENSES/`. Reference implementations and research are outside the release
tree in the Git-excluded `.local-reference/` directory.
